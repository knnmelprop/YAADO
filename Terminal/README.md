# YAADO Terminal User Interface (TUI)

The YAADO Terminal User Interface is a keyboard- and mouse-accessible cockpit built on [`Textual`](https://textual.textualize.io/). It provides an interactive environment for preliminary vehicle design, component assembly, solver execution, parameter tuning, and simulation telemetry inspection—without requiring boilerplate scripts.

## Launching the Interface

Launch the interface from anywhere within the repository:

```bash
yaado
```

*(Alternatively, via Python module: `python -m Terminal.cli` or `uv run yaado`)*

> [!TIP]
> The cockpit layout is optimized for standard maximized terminal windows (minimum recommended resolution: 120 columns by 30 rows).
